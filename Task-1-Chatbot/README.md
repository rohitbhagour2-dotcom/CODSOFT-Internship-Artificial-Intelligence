# Task 1 - Rule-Based Chatbot 🤖

## 📌 Overview

A simple rule-based chatbot that responds to user inputs using pattern matching and predefined rules. It simulates a basic conversation by recognizing keywords in the user's message and replying with a relevant, pre-set response — no machine learning involved.

This task is part of the **CodSoft Artificial Intelligence Internship**.

## 🧠 Concept Used

- **Rule-Based / Pattern Matching Logic**: The chatbot checks user input against a set of predefined keywords/patterns and returns the corresponding response.

- **If-else / Conditional Logic**: Used to map specific keywords to appropriate replies.

## ⚙️ How It Works

1. The user types a message into the chat interface.

2. The chatbot scans the input for known keywords or phrases.

3. Based on the matched pattern, it returns a relevant predefined response.

4. If no match is found, a default fallback response is shown.
